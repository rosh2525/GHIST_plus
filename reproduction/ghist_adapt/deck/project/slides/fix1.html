Recovering the signal GHIST+ throws away

GHIST+ already predicts, for every cell and gene, P(expressed) and an amount. Its export keeps only the top-K cells per gene and zeroes the rest.

Using P(expressed) × amount for every cell keeps that information. Example genes: CCND1 0.44 → 0.53, GATA3 0.47 → 0.56 (Breast5K).

Trade-off: alone it blurs spatial maps (SSIM 0.376 → 0.279) and gene–gene structure. Use it for per-gene ranking, or as the input to Fix 2.
