Background

GHIST: reading gene expression from routine H&E

Fu et al., Nature Methods 2025. Input: an ordinary H&E slide. Output: an expression value for every gene of a targeted panel, in every single cell.

Trained on 10x Xenium spatial transcriptomics measured on the same tissue section, so each nucleus is paired with its measured RNA.

Learns morphology, cell type and neighbourhood composition together, so cell identity guides the expression it predicts.

Why it matters: spatial transcriptomics is costly; H&E is in every pathology archive. Virtual molecular maps of tumour microenvironments become possible at scale.

H&E image + nucleus segmentation (HoverNet)

Per-cell morphology features

Multitask heads: expression · cell type · neighbourhood composition

Single-cell expression map of the whole slide

Preprocessing as described in the GHIST and GHIST+ papers: Xenium output parsed, H&E aligned, nuclei segmented with HoverNet, cell types from scClassify.

GHIST is the first model from this group. The key biological idea is that a cell's expression depends on what it looks like, what type it is, and who its neighbours are, so the model learns all three together. Cell-type labels come from scClassify on the measured RNA, which matters later: those labels are themselves predictions.
